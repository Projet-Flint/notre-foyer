# Notre Foyer (version web)

App du foyer installable sur iPhone depuis Safari : agenda, courses par rayon, tâches, dates, maison, contacts, travail, projets et finances.

Les données restent dans le téléphone (aucun serveur). Pour l'installer : ouvrir l'adresse GitHub Pages dans Safari, bouton Partager, « Sur l'écran d'accueil ».

Pour publier une mise à jour, changer `VERSION` dans `sw.js`.
